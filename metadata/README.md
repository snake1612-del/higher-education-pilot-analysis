# Документированный состав исследования

`scope_registry.json` содержит 16 связок когорты 2023 года и дополнительный перечень `confirmed_eventual`. Для каждой связи указаны вуз, группа МКП, статус свидетельства, источники с локаторами и доступные программные соответствия. Это авторская разметка публичных документов, а не наблюдения приёма из закрытого массива.

Первоначальная шестёрка анализируется на уровне постоянных групп вузов. В детальной когорте 2023 остаются МАИ, МИСИС, МПГУ и ТГУ. БФУ исключён из неё из-за недостаточности исторического подтверждения полного сопоставимого перечня. Для Горного различаются перевод набора 2023 после поступления и прямой набор по новой модели с 2024; есть спорная сопоставимость геологических категорий. Поэтому результаты этих вузов не выдаются за сопоставимую когорту программ 2023.

В расширенном реестре сохранены отдельные связи Горного для прозрачности исторических решений. Они не включаются в сравнение четырёх вузов: список `primary_universities` явный. Название `confirmed_eventual` означает документированную связь к 2025 году, а не полный подтверждённый набор по каждой программе. Наличие плана, учебного плана или каталога не доказывает фактическое зачисление по каждому профилю. Доля пилотных студентов внутри группы неизвестна.

Источники реестра были проверены в исследовательской работе 15 октября 2026; часть исторических страниц повторно недоступна. Это отмечено в карточках. Основной исторический источник МАИ добавлен отдельно; текущий каталог не используется как самостоятельное доказательство даты фактического первого набора.

`university_names.json` содержит шесть точных имён МКП и проверенные варианты наименований головных организаций МЭВ. `prepare_inputs.py` восстанавливает ID из локального МЭВ и останавливается при неоднозначности. Сам массив ID и числовые наблюдения не публикуются.

`mev_columns.json` сопоставляет 18 выбранных полей точным заголовкам оригинального Excel. Это схема извлечения, а не подготовленный массив данных. Мониторинг 2022–2025 соответствует отчётным годам 2021–2024; для описания до перехода используются только 2021–2022.
