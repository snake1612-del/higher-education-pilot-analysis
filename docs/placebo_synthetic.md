# Плацебо и синтетический контроль

В расширении проверяется, насколько результат зависит от способа построения фона. Цель — отличить закономерность, которая повторяется при разных сравнениях, от разрыва, который легко получить и у вузов вне пилота. Основной отчёт сохраняется: здесь меняются состав фона, способ взвешивания и, для среднего балла, год фиксации предметных весов.

**Временное плацебо.** Уже в 2021–2022 годах исходный расчёт показывал отклонения от предметного фона. В будущих связанных группах МАИ и МИСИС бюджетное зачисление росло быстрее фона на 12,06 и 11,09 п.п.; у МПГУ динамика отставала на 8,68 п.п. Это единственный допилотный интервал. Он помогает увидеть расхождения, но не даёт оценки их типичного размера во времени.

## Сравнение на одинаковых группах подготовки

Для каждого вуза взяты его группы из реестра когорты 2023. Из кандидатов исключены все шесть первоначальных участников. Допускаются только вузы, у которых по каждой группе этой корзины есть положительное бюджетное зачисление и известный средний балл. Для расчёта траекторий нужна полнота 2021–2025; в таблице отдельно виден отсев после 2021. Условие полноты зависит от данных после пилота и может создавать отбор. Результат относится к документированным связанным группам с полной историей.

| Вуз | Групп | Кандидатов в 2021 | Полная история |
|---|---:|---:|---:|
| МАИ | 1 | 31 | 28 |
| МПГУ | 2 | 97 | 91 |
| ТГУ | 8 | 3 | 2 |
| МИСИС | 5 | 12 | 8 |

Для обоих методов баллы агрегируются по одинаковым предметным весам: долям зачисления фокального вуза в 2021 году. Зачисление суммируется по корзине, затем переводится в индекс с базой 2021 = 100 внутри каждого вуза. При наличии не менее пяти кандидатов строятся два фона:

- **Разность изменений (DiD)**: каждому кандидату даётся равный вес. Из изменения фокального вуза за 2022–2025 вычитается изменение фона. Для зачисления сравниваются процентные изменения относительно 2022 года.
- **Синтетический контроль**: неотрицательные веса с суммой 1 подбираются только по значениям 2021 года. Признаки — баллы по группам, логарифм объёма зачисления и доли групп. Масштабы блоков заданы в коде: 5 баллов, удвоение размера и 20 п.п. доли; предметные блоки нормированы на корень из числа групп. Минимизируется квадрат расхождения признаков плюс квадрат отклонения весов от равномерных. После подбора веса не меняются. Для сопоставимости с DiD итоговый синтетический контраст также отсчитывается от 2022 года.

**Проверка на 2022 годе.** До переноса базы измеряется фактический разрыв с синтетической траекторией. Рабочие пороги: 2 балла и 10 пунктов индекса зачисления. Это критерии пригодности аналога для описательного сравнения, а не статистические границы. Разрыв до реформы возможен сам по себе; проверка показывает, насколько точно модель предсказывает оставленный год. Два допилотных года не позволяют надёжно оценить устойчивость этого прогноза.

**Плацебо по вузам.** Каждый кандидат по очереди становится фиктивным участником в 2023 году и исключается из своего фона. Все остальные правила и предметные веса остаются теми же. Для синтетического фона основной ориентир составляют плацебо, прошедшие тот же порог на 2022 годе по соответствующей метрике. Доля плацебо с таким же или большим абсолютным разрывом — описательная характеристика выборки, а не причинное p-значение. Для проверки зависимости от отдельного аналога модель заново оценивается без вуза с максимальным весом.

## Результат

| Вуз | Ошибка синтетики в 2022: балл / индекс | Балл к 2025: равные / синт. | Зачисление к 2025, п.п.: равные / синт. / без главного аналога |
|---|---:|---:|---:|
| МАИ | −0,27 / +8,20 | +0,24 / −0,60 | −13,22 / −8,21 / −38,14 |
| МПГУ | +2,12 / −7,04 | −0,89 / −1,17 | +9,97 / +10,30 / +7,16 |
| МИСИС | +8,47 / +6,50 | +0,44 / +0,09 | +12,17 / +11,20 / −24,86 |
| ТГУ | — | — | — |

- **МПГУ.** Опережение по зачислению сохраняет знак при двух фонах и после исключения крупнейшего аналога. При этом абсолютный синтетический разрыв такого размера или больше получился у **31 из 64** подходящих плацебо. Это устойчивый к замене фона описательный результат, но величина не выделяется среди вузов без пилота.
- **МАИ.** Отставание по зачислению сохраняет знак, но сильно меняется по величине. На главного аналога приходится 77,7% веса. По баллам знак зависит от метода; оба разрыва малы.
- **МИСИС.** Синтетический аналог не воспроизводит уровень баллов в оставленном году. Для зачисления базовый результат положительный, но модель отдаёт одному вузу весь вес, и без него знак меняется.
- **ТГУ.** Два кандидата с полными рядами недостаточны по принятому правилу. Это ограничение данных; оценка не подставляется из другого набора групп.

Совпадение знаков не делает оценки независимыми: обе используют один массив и общий пул кандидатов. Зачисление зависит в том числе от предложения мест и не измеряет заявки. Результаты не устанавливают эффект пилота.

## Локальное воспроизведение

Используется разрешённый бюджетный CSV из сценария подготовки данных. В JSON остаются веса и производные ряды отдельных вузов; его следует хранить локально и не публиковать.

```bash
python src/placebo_synthetic.py --mkp-csv outputs/inputs/mkp_budget.csv --output outputs/placebo/counterfactuals.json
python src/build_placebo_figures.py --results outputs/placebo/counterfactuals.json --output outputs/placebo
python src/build_public_placebo_summary.py --results outputs/placebo/counterfactuals.json --assets assets
python src/build_preperiod_placebo.py outputs/comparisons.json metadata/university_names.json outputs/placebo/placebo_2021_2022.png
```

В README включены только сводные контрасты трёх фокальных вузов и числа плацебо. Траектории и отдельные точки плацебо строятся локально.

Методические источники: [Abadie, Diamond & Hainmueller (2010)](https://economics.mit.edu/sites/default/files/publications/Synthetic%20Control%20Methods.pdf); [Abadie (2021)](https://economics.mit.edu/sites/default/files/publications/jel.20191450.pdf).
