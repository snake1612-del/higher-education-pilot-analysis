# Запуск и устройство SQL анализа

SQL-часть исследовательского проекта Борисенко Владислава для хакатона ИВО 2026.
Исследовательский вопрос: стали ли первоначальные участники пилота привлекательнее для абитуриентов?

Здесь восстановлен путь от широкого сравнения вузов к анализу постоянных групп,
предметного фона, структуры приёма и поступления без вступительных испытаний.
Код рассчитан на PostgreSQL и пригоден для выполнения из SQLTools или psql.

**Происхождение кода.** Ранние сравнения выполнялись в PostgreSQL. Итоговые проверки
исследования рассчитывались в Python. Файлы `04`–`08` — последующая SQL-реконструкция
основных расчётов, а не архив всех запросов в первоначальном порядке.
Результаты реконструкции сверены локально с проверенными расчётными таблицами.

## Входные данные и запуск

Рекомендуемый единый запуск из исходных Excel описан в [инструкции](../docs/reproduction.md). Ниже сохранён ручной маршрут. Нужны разрешённый доступ к исходным массивам и опубликованный [реестр с источниками](../metadata/scope_registry.json). CSV реестра создаёт `src/prepare_inputs.py`.
В репозитории нет исходных данных, производных числовых таблиц или выгрузок БД.
Описание входов находится в [data/README.md](../data/README.md).

1. Подключиться к отдельной базе проекта и выполнить `sql/00_schema.sql`.
2. Загрузить 19 исходных столбцов бюджетного листа в `research_raw.mkp_budget`.
3. Загрузить проверенный реестр в `research.scope_links`.
4. Выполнить `01_prepare_data.sql`, затем `02_quality_checks.sql`.
5. Выполнить `04_fixed_panels.sql`, затем `11`, `12` и запросы `03`, `05`, `06`, `07`, `08`.
6. Для дополнительного описания по МЭВ использовать `09` по отдельной инструкции.

Пример загрузки из **psql**:

```sql
\copy research_raw.mkp_budget FROM '/absolute/path/mkp_budget.csv' WITH (FORMAT CSV, HEADER TRUE, DELIMITER ';', ENCODING 'UTF8')
\copy research.scope_links FROM '/absolute/path/scope_links.csv' WITH (FORMAT CSV, HEADER TRUE, DELIMITER ',', ENCODING 'UTF8')
```

`\copy` — команда клиента psql, а не обычный SQL для SQLTools.
Пути в примере нужно заменить своими. Повторная загрузка добавляет строки:
не импортировать один и тот же файл повторно в заполненную таблицу.
Таблица `public.mkp_budget_raw`, если она уже есть, этими файлами не изменяется.

Очистка и основные промежуточные слои материализованы, чтобы не повторять
разбор текста и агрегации при каждом запросе. После обновления исходных данных
нужно заново выполнить `01`, `02`, `04`, затем запросы результатов.
После изменения только реестра связей — `02`, `04`, затем запросы результатов.
Старые результаты до обновления материализованных слоёв считать неактуальными.

## Что важно для интерпретации

- Строка данных — группа подготовки в вузе. Связанная группа может включать другие программы.
- Число зачисленных не равно числу заявлений или плановым бюджетным местам.
- Пропуск БВИ не превращается в ноль. Для баллов и БВИ формируются разные панели.
- Баллы групп взвешиваются численностью приёма как приближением: индивидуальный знаменатель официального среднего неизвестен.
- В основном расчёте баллов фиксированы веса между группами, а внутри группы веса контролей текущие. `11` фиксирует оба уровня как альтернативу.
- Зачисление `metric=score` и `metric=intake` различается правилами отбора и доступным фоном; нули допустимы во втором варианте.
- Внешний фон согласован по группам и исключает всех шестерых первоначальных участников.
- Масштабированные количества фона — расчётные величины, не реальные люди одного университета.
- Остальные наблюдаемые группы внутри вуза нельзя автоматически назвать непилотными.
- Доля связанных групп на постоянной панели не равна доле пилотных студентов во всём вузе.
- Баллы и БВИ методически связаны. Описательный контраст не устанавливает причинный эффект.

Реконструкция не включает полный алгоритм подбора аналогов и проверку смены
широкого фона на подобранный. `09` описывает характеристики, но не выполняет matching.
Исторические исследовательские файлы сохранены локально. Они не являются проверкой устойчивости публикуемого сценария. Основные результаты независимо воспроизводит `src/independent_check.py`.
